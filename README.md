# VOSC-Activity-1

simple tic tac toe game 

## Project Structure

The project consists of exactly three main files:
- `index.html` - Handles the markup structure and layout.
- `style.css` - Provides the minimalist, modern layout aesthetics.
- `script.js` - Contains the game logic, turn management, and win/draw detection.

## How to Run / Play

1. **Download or save** these files into a single folder on your local computer.
2. Ensure all three files (`index.html`, `style.css`, and `script.js`) reside in the exact same directory.
3. Open `index.html` using any modern web browser (e.g., Chrome, Firefox, Safari, Edge).
4. Click on any empty cell to place your symbol (`X` always starts first).
5. The top status text will track whose turn it is, and immediately announce when a player wins or if the match ends in a draw.
6. Click the **Reset Game** button at the bottom to clear the board and start a new match.
